# Multilearn 

Multilearn is an innovative online learning platform designed to simplify the learning experience. With so many educational resources scattered across platforms like YouTube, Coursera, Udemy, and others, learners often waste time switching between sites and trying to keep track of where they left off. Multilearn solves this problem by bringing everything together in one place.

Check it out 👉 [here](https://multilearn-f2px.onrender.com/) 👈

# Features

Unified Course Search – Search across multiple learning platforms in one place.

Course Storage – Save courses you’re taking and pick up right where you left off.

Smart Suggestions – Get new course recommendations based on your learning history.

Quizzes – Take quizzes on any course of your choice to reinforce learning.

Responsive UI – Clean design with HTML, CSS, and JavaScript.

PostgreSQL Database – Robust backend for storing user data and courses.

# Tech Stack

Backend: Django (Python)

Frontend: HTML, CSS, JavaScript

Database: PostgreSQL
